# Historical question data

- Archive: [Krillion Answers](https://krillionanswers.com/)
- Archive methodology: [Data sources](https://krillionanswers.com/data-sources/)
- Terms reviewed: [Terms of use](https://krillionanswers.com/terms/)
- Retrieval date: September 15, 2026
- Included: 48 distinct prompts, 2,800 published scored canonical answers
- Excluded: unscored suggestions, quips, prose, page implementation, art, and keyword aliases

The archive's rare-answer summary contains only selected rare previews. The game instead uses the full scored answer lists served by the public question pages. Per-question URLs, normal public data endpoints, expected counts, retrieval details, source appearance IDs, and original response hashes are retained in `public/data-provenance.json`.

This is a selected catalog with complete answer lists for its questions, not all historical questions or the original Unlimited database. Three selected lists combine records from multiple appearances. `sourceDate` describes the latest appearance listed by the archive, not a uniform date for every answer's score.

The archive says it imports published official reveals and does not routinely human-review those records. We verified the published list counts, accepted score values, uniqueness, and answer matching. That does not establish that every archived factual answer is current or correct.

The app's source link is visible on the home screen and each completed question. This independent fan game makes no claim of affiliation or official grading.
